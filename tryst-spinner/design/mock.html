Tryst::Spinner

Indeterminate activity ring + determinate progress ring, one shard. AA stroke with round caps is the whole visual payoff - Tk's own ttk::progressbar indeterminate mode has neither.

Indeterminate - sizes 16 / 24 / 48px, thickness scales with size

Continuous rotation with the arc length oscillating between ~12% and ~88% of the ring - not a fixed wedge just spinning in place. CSS expresses this exactly for the mock; the real widget drives the same two numbers (rotation angle, arc sweep) from a Tween each tick and redraws with tryst-vector.

Determinate - value 0 to 1, optional centered number

Arc sweeps clockwise from 12 o'clock, 0 at empty to a full ring at 1.0. The center number is opt-in (show_value: true) - most determinate uses (a background sync ring, a save-in-progress indicator) don't want a number, some do.

Playground

Same knobs as the constructor: size:, thickness:, accent: "#rrggbb"? (nil = theme accent, matching tryst-value-slider), value: Var(Float64)? (nil/absent = indeterminate), show_value: Bool.
